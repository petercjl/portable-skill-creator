# Verification matrix

Package eligibility is capability-based. Native host evidence is separate from package lifecycle and OS CI evidence.

- Generic and arbitrary valid Agent identifiers: package lifecycle tests; explicit destinations, refusal and isolation.
- Codex/macOS: current execution host; native loading and exact public install verification follow publication.
- Windows and Linux: implemented; actual CI outcome determines OS test evidence.
- SealSeek native capabilities: unresolved, no local synchronization requested.
- Clean-context Skill regression: not requested; not run.
- First standalone release: no prior standalone updater found in npm registry on 2026-10-30. The historical suite is independently owned and is not replaced by this release.

The routed hybrid knowledge layer is preserved. No private Wiki is required at runtime. Packaging changes add lifecycle guidance and a generic capability adapter; they do not revise the underlying creation methodology. Source provenance is the existing portable-skill-creator, with no copied platform base creator.
